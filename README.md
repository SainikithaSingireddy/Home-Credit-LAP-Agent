# Home Credit LAP Voice Agent

## Project Overview
This project demonstrates an AI voice agent designed to conduct initial eligibility screening for a Loan Against Property (LAP) offer for existing Home Credit customers.

The agent is configured using Retell AI and follows predefined business rules to collect customer information, identify basic eligibility, and determine the appropriate next step.

## Key Features
- Customer identity verification
- Initial eligibility screening
- Property type and ownership checks
- Property document availability checks
- Loan amount and repayment tenure checks
- Income source screening
- Handling of existing property loans and EMI transfer requests
- Structured post-call analysis

## Technology Used
- Retell AI
- Prompt Engineering
- AI Voice Agents
- Markdown documentation

## Testing
Test scenarios and observed results are documented separately in `test_scenarios.md` and `test_results.md`.

## Important Note
This agent performs preliminary eligibility screening only. It does not guarantee loan approval, final loan amount, or interest rate.
